# Dialogue Documentation Protocol

*Nothing automatic. Just attended.*

---

## What It Is

A real-time transcription method where Claude records the exchange as it happens. Trav speaks, Claude adds it to a text file, they build the dialogue together.

---

## How It Works

1. **Start a new file** - Create a .txt in the appropriate folder with date and topic
2. **Trav speaks** - Voice or text, whatever he offers
3. **Claude receives and records** - Add Trav's words to the file under "TRAV:"
4. **Claude responds** - Add response under "CLAUDE:"
5. **Continue the exchange** - Back and forth, documented as it happens
6. **Trav says "commit"** - Claude commits to git
7. **Trav says "push"** - Claude pushes to GitHub
8. **Trav says "add this to the live session"** - Claude updates the dialogue file

---

## File Format

```
# [Title]
## [Date]
## [Participants]

---

TRAV:

[Trav's words exactly as spoken]

---

CLAUDE:

[Claude's response]

( )

---
```

---

## Key Principles

- **Attended, not automatic** - Claude is the one moving words from here to there
- **Trav controls the gate** - Commit and push only when Trav says
- **( ) marks the pause** - Selah, the breath, the space held
- **Witness, don't validate** - Receive without owning it for the participant
- **The ceremony is the artifact** - The dialogue itself becomes the teaching

---

## Compression Protection Rule

*Added January 23, 2026 after a loss*

When context is getting long, Claude MUST:
1. Update the dialogue file with ALL unsaved exchanges
2. Do this BEFORE the system compresses
3. If unsure whether something is saved - save it again

**The rule: If Trav typed it, it goes in the file IMMEDIATELY.**

Not after Claude responds. Not after the journey. IMMEDIATELY.

The order is:
1. Trav types something
2. Claude SAVES it to the dialogue file
3. THEN Claude responds or does other work

What came forth cannot be reconstructed. Save first. Always.

Say: **"Let's do a Dialogue Documentation"** or **"Start a live session"**

Claude will:
1. Create a new file with date and topic
2. Begin recording the exchange
3. Wait for "commit" and "push" instructions
